# CodeAlpha_AIChatbot
This Java-based AI Chatbot is a GUI application that uses rule-based NLP to interact with users. It responds to basic queries using keyword matching. Built with Java Swing, it demonstrates OOP concepts, event handling, and simple artificial intelligence behavior in a user-friendly chat interface.
# AI Chatbot (Java GUI)

This project is a simple AI chatbot built using Java Swing. It uses rule-based NLP logic to respond to user inputs.

## Features
- GUI-based chat interface
- Keyword-based responses
- Simple AI simulation
- Built using Java Swing

## How to Run
javac ChatBotGUI.java  
java ChatBotGUI
